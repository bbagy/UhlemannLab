DADA2 / Amplicon

daDake2

DADA2 amplicon pipeline for Illumina 16S (V3–V4, V1–V2) and ITS sequencing. Runs natively with R + qiime2; no Docker required. Each pipeline step writes an RDS checkpoint so interrupted runs resume without repeating learnErrors.

STATUS: AVAILABLE — TESTED IN CORE4 WORKSTATION

Supported Types

Type flagRegionPrimer trimHost removal
standard_V3V416S V3–V4trimLeft onlyYes (NA phylum, Chloroplast, Mito)
zymo_V1V216S V1–V2 (Zymo)trimLeft onlyYes
illumina_ITSITS (Fungi)cutadaptNo

Pipeline Flow

Paired FASTQ→ [ITS] cutadapt→ filterAndTrim→ learnErrors→ dada + merge→ chimera removal→ assignTaxonomy→ phyloseq + CSV→ qiime2 tree

Gray node (cutadapt) runs only for illumina_ITS.

Operational Notes

  • DATE is fixed at pipeline launch (yymmdd) and baked into all filenames — rerunning on a different day never overwrites prior outputs.
  • Small samples (< -m bytes) are written to failed.csv at DAG construction time before any rules run.
  • Samples with zero reads after filterAndTrim are appended to failed.csv and excluded from downstream steps.
  • Host removal (NA phylum, Chloroplast, Mitochondria) applies to 16S types only.
  • addSpecies() is not used; no species DB needed.
  • Mapping template CSVs (3_map/) are generated for 16S types only.
  • qiime2 tree step calls conda run -n qiime2 qiime ... directly.
  • Lock errors are auto-handled by the wrapper (--unlock then retry).
