HUMAnN3 / MetaPhlAn4

Humann

Shotgun metagenome functional profiling with HUMAnN3 + MetaPhlAn4, including merged gene-family / pathway tables, optional MUSiCC correction, and KEGG orthology regrouping.

STATUS: AVAILABLE — TESTED IN CORE4 WORKSTATION

Pipeline Flow

Prefilter + R1/R2 merge→ HUMAnN3 per-sample→ MetaPhlAn4 bug list→ join_tables→ renorm CPM→ regroup UniRef90_rxn→ MUSiCC (opt)→ rename KEGG-orthology→ stratified split

Build

cd Humann
docker build --network=host -t humann:1.0 .

Run

./Humann/Go_Humann.sh \
  -i /path/to/host_filtered_fastq \
  -o humann_run \
  -n /path/to/chocophlan \
  -p /path/to/uniref \
  -b /path/to/metaphlan_db \
  -I mpa_vJan25_CHOCOPhlAnSGB_202503 \
  -c 8 -j 4 -t 4 \
  --run-musicc \
  -K

Real Example

Go_Humann.sh \
  -i Humann/20261101_MG_HKP_nohuman \
  -o Humann/20261101_MG_HKP_humann_out \

Options

FlagDescription
-iInput host-filtered FASTQ directory
-oOutput directory
-nHUMAnN3 nucleotide DB (chocophlan)
-pHUMAnN3 protein DB (uniref)
-bMetaPhlAn4 DB directory (or legacy .pkl)
-IMetaPhlAn4 index basename
-c / -j / -tSnakemake cores / jobs / HUMAnN threads
-xDry-run
-KKeep-going
--run-musiccEnable MUSiCC correction
--skip-gene-normSkip gene-family normalization
--skip-path-splitSkip stratified/unstratified split

Notes

  • Recommended MetaPhlAn input: -b <dir> + -I <index_basename>; .pkl shortcut auto-resolves for legacy use.
  • Paired _R1 / _R2 (including _nohuman variants) are merged per sample into 7_intermediate/<sample>.merged.fastq.gz before HUMAnN runs.
  • Per-sample .humann.done markers allow safe resume after interruption.
  • --run-musicc enables MUSiCC correction on the regrouped KO table.
